ScatterReduce算子分析

  • 五个参数
    • dim
      • 替换的维度
    • index
      • 索引矩阵，用这个来替换self
    • src
      • 源矩阵，shape和index一样
    • reduce
      • 操作类型
      • string类型
      • 值有：sum, prod, mean, amax, amin
    • include_self=True
      • bool
  • 定义
Classify Name Type TypeRangeAll Format
INPUT self Tensor fp32, fp16 ND
INPUT index Tensor int32 ND
INPUT src Tensor fp32, fp16 ND
OUTPUT y Tensor fp32, fp16 ND
REQUIRED_ATTR dim int32 ~ ND
REQUIRED_ATTR reduce str sum, prod, mean, amax, amin ND
ATTR include_self bool True, False ND
