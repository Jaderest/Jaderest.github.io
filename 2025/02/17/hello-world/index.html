基础环境搭建

安装node.js

  1. 下载地址：node.js
  2. 下载对应版本的安装包，安装node.js，一路点击下一步即可
  3. 安装完成后，打开cmd，输入node -v和npm -v，查看是否安装成功
  4. 安装hexo
  5. 安装 hexo 部署 git 插件

配置git，并配置ssh key

  1. 检查本地是否存在ssh key
  2. 生成ssh key
  3. 查看ssh key
    找到.ssh文件夹，打开id_rsa.pub文件，复制里面的内容
  4. 配置github
    将公钥添加到github的ssh key中
  5. 测试是否配置成功
