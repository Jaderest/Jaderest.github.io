SSH协议

SSH协议

Secure Shell，是一种用于安全远程登录和其他网络服务的加密协议

工作原理

1. 连接建立

  • 客户端连接到SSH服务器的指定端口（默认22）
  • 服务器发送公钥给客户端
  • 客户端验证服务器的公钥
  • 客户端和服务器协商加密算法和压缩算法（如AES、RSA等）
  • 客户端生成一个会话密钥，并用服务器的公钥加密后发送给服务器
  • 使用会话密钥进行后续通信

2. 用户认证

  • 密码认证
    • 客户端发送用户名
    • 服务器请求密码
    • 客户端发送加密的密码
    • 服务器验证密码，返回认证结果
  • 公钥认证
    • 客户端发送用户名和公钥
    • 服务器发送一个随机数
    • 客户端用私钥加密随机数并发送给服务器
    • 服务器用公钥验证签名，验证成功后返回认证结果

3. 数据传输

  • 身份验证成功后SSH建立一个加密的会话通道
    • 远程登录：在远程主机上执行命令
    • 文件传输：使用SCP或SFTP协议
    • 端口转发：将本地端口映射到远程主机的端口或反之

语法制导定义

  • 如下例子的作用则是将中缀表达式转化乘后缀表达式，其中的code就是属性

语法制导翻译

SDD

  • Syntax-Directed Definition 是上下文无关文法和属性/规则的结合
    • 属性和文法符号相关联，按需确定各个文法符号需要哪些属性规则和产生式相关联
  • 文法符号X和属性a，X.a表示分析树中某个标号为X的结点的值
    • 分析树结点和它的分支对应一个产生式规则
    • 语义规则确定了这些结点上属性的取值和计算

      属性按需设置，例如我们需要知道它的类型type，和内存位置place

      • 产生式规则：E -> E1 + T
        • 假设只有int/float两种类型
        • E.type = if(E1.type == T.type) then T.type else float;
        • E.place = newtemp(); // 返回一个新的内存位置
